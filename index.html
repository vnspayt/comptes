Règles de catégorisation

Chaque catégorie est associée à des mots-clés. Si le libellé d'une transaction contient un de ces mots, elle est classée automatiquement — sur les imports comme sur les tickets analysés.

Efface définitivement toutes les transactions, tous les tickets enregistrés et remet les règles par défaut. Action irréversible.
